# Aucfree の画像を復元する(もとい魚拓)

**バージョン: Ver1.1**

Aucfreeの商品ページや検索結果で表示できなくなった画像を、対応するYahoo!オークションの商品ページなどから取得して表示するユーザースクリプトです。表示の復旧に加え、取得できた商品画像と商品情報をブラウザー内に保存し、あとから確認できます。

## 作成の背景

Aucfreeに掲載された商品ページでは、画像が欠落したり、画像配信元から取得できなくなったりすることがあります。商品IDを手掛かりにYahoo!オークションの対応ページを調べ、画像を復元できる場合はページに表示するのがこのスクリプトの基本機能です。

復元した画像や商品情報を後日も確認できるように、画像データはIndexedDBに、商品情報は同じIndexedDB内の別ストアに保存します。Yahoo!側から情報を取得できない場合は、Aucfree側のページを代替取得元として確認します。

## 対象環境

- `https://aucfree.com/*` および `https://www.aucfree.com/*`
- `GM_xmlhttpRequest` と `@connect` に対応するTampermonkeyなどのユーザースクリプト管理ツール
- IndexedDBとlocalStorageが利用できるブラウザー

保存データは、スクリプトを実行したブラウザープロファイル内に保存されます。別のブラウザーや端末とは共有されません。

## インストールと使い方

1. Tampermonkeyなどのユーザースクリプト管理ツールをブラウザーに追加します。
2. このリポジトリの [`restore-aucfree-images.js`](./restore-aucfree-images.js) を開き、管理ツールの新規スクリプトとして登録します。
3. 管理ツールでスクリプトが有効になっていることを確認します。Yahoo!オークションとAucfree、画像配信元への接続許可が表示された場合は、内容を確認して許可してください。
4. Aucfreeの商品ページまたは検索結果ページを開きます。ページ内の商品情報を検出すると、スクリプトが必要な画像・情報を順次確認します。

### ページ上の表示

ページ右下に「このページのキャッシュ進捗」が表示されます。画像とテキストそれぞれについて、処理した件数のうち保存できた件数、処理中の件数、失敗した件数を確認できます。この表示は**現在のページで処理したデータの進捗**であり、ブラウザーに保存された全商品の総数や容量ではありません。

進捗表示の上にある **「キャッシュデータを確認」** を押すと確認画面が開きます。商品ID（例: `s1234567890`）またはAucfreeの商品URLを入力して **「表示」** を押すと、保存済みの商品情報、商品紹介文、Full-size画像を確認できます。データがまだ保存されていない場合は、該当項目にキャッシュがない旨が表示されます。

### ページごとの動作

- **検索結果**: ページ内で検出したすべての商品カードを対象に処理します。欠落画像があれば、取得できた先頭画像をサムネイルとして表示します。
- **商品詳細**: 欠落した商品画像や説明画像を、取得できた画像で復元します。画像取得と保存は別々に行うため、保存できない場合でも元の画像URLから表示できることがあります。
- **ページ内遷移**: AucfreeのURL変更や、ページ内容の追加・更新も監視して処理します。
- **商品情報**: Yahoo!の商品ページから商品タイトル、本文、商品紹介文、取引日時、価格などを抽出して保存します。Yahoo!から取得できない場合はAucfree側を代替取得元として使います。

画像の並びや掲載内容は、元ページから抽出できた情報に依存します。サイトのHTML構造や画像配信方法が変わった場合は、復元できないことがあります。

## 保存されるデータ形式

### IndexedDB

IndexedDBデータベース名は `aucfree-yahoo-image-bytes`、データベースバージョンは `2` です。次の2つのObject Storeを使います。

#### `images` — 画像と画像一覧情報

| 内容 | キー | レコード形式 |
|---|---|---|
| 商品画像 | `{商品ID}:full-size:{番号}` | `{ key, blob }` |
| 商品説明内の画像 | `{商品ID}:item-description:{番号}` | `{ key, blob }` |
| 検索結果用サムネイル | `{商品ID}:thumbnail` | `{ key, blob }` |
| 画像一覧の確認情報 | `{商品ID}:manifest` | `{ key, formatVersion, expectedFullSizeCount, expectedDescriptionCount, updatedAt }` |

画像番号は0から始まります。`blob` が画像本体です。manifestは画像の想定件数などを記録するメタデータで、画像データそのものではありません。

#### `auction-text` — 商品情報

商品IDをキー（`id`）として、次の形式のレコードを保存します。

```text
{
  id,
  sourceUrl,
  capturedAt,
  title,
  auctionDate,
  price,
  text,
  descriptionText
}
```

- `sourceUrl`: 情報を取得したYahoo!またはAucfreeの商品ページ
- `capturedAt`: 取得日時（ISO 8601形式）
- `title`: ページタイトル
- `auctionDate`: 終了日時・落札日時・取引日時として抽出できた値
- `price`: 落札価格として抽出できた値
- `text`: 商品ページ本文のテキスト
- `descriptionText`: 商品説明領域から抽出したテキスト

取得元ページに該当情報がない場合、日時や価格などの値は空文字になることがあります。

### localStorage

画像URL一覧などの軽量なメタデータを商品ごとに保存します。キーは `aucfree-yahoo-image:{商品ID}`、値はJSON形式で、主な項目は次のとおりです。

```text
{
  gallery: ["画像URL", "..."],
  description: ["説明画像URL", "..."],
  imageCacheFormatVersion: 1,
  noImages: false,
  checkedAt: "ISO 8601形式の日時"
}
```

画像本体はlocalStorageには入らず、IndexedDBのBlobとして保存されます。したがってlocalStorageの値だけでは画像を表示できません。

### Edge・ChromeでのIndexedDB保存場所（Windows）

Chromium系ブラウザーでは、IndexedDBのデータはユーザープロファイル内にブラウザーが管理するファイルとして保存されます。標準的なプロファイル（`Default`）の場合、AucfreeのIndexedDBデータベースは次の場所にあります。

- **Google Chrome**: `%LOCALAPPDATA%\Google\Chrome\User Data\Default\IndexedDB\https_aucfree.com_0.indexeddb.blob or leveldb\`
- **Microsoft Edge**: `%LOCALAPPDATA%\Microsoft\Edge\User Data\Default\IndexedDB\https_aucfree.com_0.indexeddb.blob or leveldb\`

画像Blobは同じ `IndexedDB` フォルダー内の `https_aucfree.com_0.indexeddb.blob` フォルダーに保存される場合があります。`Default` は使用中のプロファイル名（例: `Profile 1`）に置き換わることがあり、ブラウザーやバージョンによって実際の保存場所・ファイル構成が異なる場合もあります。ブラウザーのアドレス欄で `edge://version` または `chrome://version` を開き、「プロフィール パス」を確認すると、使用中のプロファイルの場所を特定できます。

これらはブラウザー内部の管理用データです。ファイルを直接編集・移動せず、バックアップや確認のために扱う場合も、まずブラウザーを終了してください。保存済みデータの確認には、上記の「キャッシュデータを確認」画面を使う方法を推奨します。

## 保存期間と削除

スクリプトは `navigator.storage.persist()` による永続化を要求しますが、これは保存を保証するものではありません。有効期限による自動削除は行いませんが、ブラウザーのサイトデータ削除、容量不足時の処理、プロファイル削除、端末故障などでデータが失われることがあります。大切なデータは別途バックアップしてください。

保存データを削除するには、ブラウザーのサイトデータ管理からAucfreeのサイトデータを削除してください。IndexedDBだけ、またはlocalStorageだけを個別に消すと、画像本体とURL一覧の不整合が起きることがあります。スクリプトにはキャッシュの一括エクスポート・削除機能はありません。確認画面はキャッシュの閲覧用です。

## 通信と権限

Yahoo!の商品ページ、Aucfreeの代替ページ、および画像を取得するため、ユーザースクリプト管理ツールの `GM_xmlhttpRequest` を使用します。スクリプトではYahoo!/Yimg、Aucfree、`auction-labo.com`、`yafuokugazo1.but.jp` への接続を宣言しています。画像取得は最大20秒、Yahoo!の商品情報取得は用途により最大6〜8秒、Aucfreeの代替取得は最大10秒でタイムアウトします。

このスクリプトはYahoo!オークションの商品ページにもアクセスします。そのアクセスがYahoo!側の閲覧履歴やおすすめ表示に反映されるため、影響を受け入れたうえで使用するか、Yahoo!オークションにログインしていないブラウザー環境で実行してください。

複数の商品を同時に処理すると、Aucfree側からHTTP 403 Forbiddenが返され、一時的に商品情報を取得できなくなる場合があります。その場合はJavaScript内の `minAucfreeTextRequestInterval`（ミリ秒）を大きくして、Aucfreeへの商品情報リクエスト間隔を調整してください。既定値は `1000`（1秒）です。変更後はユーザースクリプトを保存し、必要に応じてAucfreeのページを再読み込みしてください。

## 検証について

このスクリプトは深い検証や、あらゆる商品・ページ構成での動作確認を行ったものではありません。取得できる情報や復元結果の正確性・完全性を過信せず、必要に応じて元ページや保存データを確認したうえでご利用ください。

## トラブルシューティング

- **画像が復元されない**: 対象ページのURLがAucfreeの商品ページ・検索結果ページか、管理ツールでスクリプトが有効かを確認してください。商品IDや元ページの画像が取得できない場合は復元できません。
- **検索結果で処理が始まらない**: 商品カードのリンクから商品IDを取得できるか、右下の進捗表示やブラウザーConsoleのエラーを確認してください。
- **画像は表示されるが保存に失敗する**: 右下の進捗表示を確認し、ブラウザー設定でIndexedDBが利用可能か、空き容量があるかを確認してください。管理ツールの接続許可や画像配信元への通信も確認してください。
- **商品紹介文・画像が一部ない**: 元ページの情報が取得できなかった、または説明欄の形式が抽出対象と異なる可能性があります。
- **確認画面にキャッシュが表示されない**: 正しい商品IDまたはAucfree商品URLを入力してください。その商品をまだ処理していない場合、保存データはありません。
